Use `Tabs` and `Tab` to show alternatives such as package-manager commands. Both components are built into `.mdx` pages—no imports are required. Each `Tab` has a `value` matching one of the strings in `items`.

## Install demo

Choose a package manager, then try the second demo below. Both groups use `groupId="package-manager"`, so selecting a tab updates the other group too.

## Selection and storage

Without a `groupId`, each group is independent and starts at `defaultIndex`. With a `groupId`, selections synchronize between matching groups and are saved in `sessionStorage` by default. Add `persist` to use `localStorage` and remember the preference across browser sessions. Use the same `persist` setting on groups that share an ID.

A saved value takes precedence over `defaultIndex` only when it appears in that group's `items`. If browser storage is unavailable, tabs still work with their default selection and in-page synchronization. `persist` has no effect without a `groupId`.

Keep `items` unique and provide one matching `Tab` per item. Leave blank lines around Markdown inside the panels. Panels do not require a context provider or an additional wrapper.

## Keyboard controls

Tab into the selected tab. **Left Arrow** and **Right Arrow** select and focus the previous or next tab, wrapping at either end. **Home** selects the first tab; **End** selects the last. Tab again to move into the selected panel. Tabs expose tablist, tab, and tabpanel roles with linked labels.
